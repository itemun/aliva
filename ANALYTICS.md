# Аналитика Aliva

Счётчик Яндекс Метрики **114646189**. Публичный сайт: https://itemun.github.io/aliva/. Обновлено 24.11.2026.

## Автоматический запуск

По прямому указанию владельца от 24.11.2026 Метрика запускается автоматически при открытии публичного сайта. Запрос согласия и «Настройки аналитики» удалены. Приложение больше не читает и не записывает прежний ключ `aliva.analytics-consent.v2`; старые значения не управляют запуском. В тексте конфиденциальности сохранено описание технических данных, cookie и получателя статистики.

Стандартный флаг запрета `disableYaCounter114646189`, установленный до запуска, не перезаписывается: тег не загружается при его значении true. Блокировщики и ограничения браузера могут уменьшать охват. Отсутствие счётчика не ограничивает анкету и PDF.

## Что измеряется

Посещаемость, технические характеристики устройства/браузера, источник перехода (домен), время и отказы; карта кликов вне анкеты; достижение общих разделов и этапов. Первый URL очищается от query/hash, referrer — до origin. UTM и поисковые запросы намеренно не извлекаются приложением. Метрика использует IP-адрес, cookie и идентификаторы браузера: данные не называются полностью анонимными.

| Идентификатор цели | Значение |
| --- | --- |
| aliva_app_store_click | Нажатие App Store |
| aliva_google_play_click | Нажатие Google Play |
| aliva_pdf_download | Личный PDF создан, браузеру передана команда скачать |
| aliva_example_pdf_download | Пример PDF создан, браузеру передана команда скачать |
| aliva_questionnaire_open | Нажатие CTA перехода к анкете |
| aliva_questionnaire_start | Первое изменение поля анкеты, без имени и значения поля |
| aliva_profile_complete | Успешно пройден общий шаг основных данных |
| aliva_measurements_complete | Успешно пройден общий шаг измерений |
| aliva_plan_ready | Успешно сформирован личный результат |
| aliva_view_how_it_works | Раздел «Как это работает» пересёк центральную область экрана |
| aliva_view_example | Раздел примера пересёк центральную область экрана |
| aliva_view_sources | Раздел оснований пересёк центральную область экрана |
| aliva_view_app | Заголовок приложения пересёк центральную область экрана |

В кабинете созданы цели типа «Целевое событие», точное совпадение идентификатора. Этапы и просмотры отправляются один раз за загрузку страницы; отдельные нажатия магазинов и скачивания считаются отдельно. Просмотр означает появление области на экране, не подтверждает чтение. Скачивание не подтверждает сохранение файла на диск; нажатие магазина не является установкой приложения.

## Граница медицинских данных

Ответы, пол, возраст, выбранная страна, диагнозы, измерения, рассчитанные показатели, состав плана и содержимое PDF не добавляются в аналитику. Условные шаги курения и уточнения не отслеживаются: их последовательность сама может раскрыть ответ. События `reachGoal` не имеют дополнительных параметров. DOM анкеты исключён из карты кликов через `ym-disable-clickmap`, также сохранены `ym-hide-content ym-disable-submit ym-disable-keys`.

Вебвизор и аналитика форм выключены: запись общей страницы может раскрыть выбор и условные поля даже при маскировке текста. Данные о прохождении лендинга заменены явно заданными общими событиями. Автоматические цели, отслеживание ссылок/хешей, ecommerce и Тег Менеджер выключены. Ссылки на медицинские источники не отслеживаются.

Статистика загружается только на HTTPS-хосте itemun.github.io с путём /aliva/. Локальные страницы и скачанный HTML остаются автономными. При смене домена обновите проверку адреса. CSP разрешает только перечисленные адреса Метрики; вспомогательный iframe остаётся заблокирован. PDF не зависит от внешних сервисов.

## Проверки и ограничения

Автотесты проверяют автоматический однократный запуск, отсутствие интерфейса согласия и обращений к хранилищу, точный список целей, отсутствие медицинских параметров, обработку ошибки счётчика, стандартный флаг запрета и ограничение домена. Браузерная проверка дополнительно подтверждает реальные запросы, отсутствие дублирования и сохранение защиты анкеты.

Техническая настройка не является заключением о соответствии всем применимым законам. Для окончательного текста политики запрошены у владельца имя/наименование оператора и контакт для обращений; реквизиты не выдумываются. Сроки хранения у Яндекса и обработка обращений требуют проверки владельцем.

Основания: [уведомление и отложенная загрузка](https://yandex.ru/support/metrica/ru/general/notification), [отказ от сбора](https://yandex.ru/support/metrica/ru/general/user-opt-out), [исключение элементов](https://yandex.ru/support/metrica/ru/code/html-markup), [условия сервиса](https://yandex.ru/legal/metrica_termsofuse/ru/). Проверено 24.11.2026.

Для интеграций доступно событие `aliva:conversion` при активном счётчике; detail содержит только goal. Не подключайте второй обработчик reachGoal. Никаких ответов или событий не хранить в журналах или GitHub.

Сборка: `npm run build`. Проверки: `npm test`.
