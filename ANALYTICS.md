# Целевые действия Aliva

Подключён счётчик Яндекс Метрики **114646189** (24.11.2026). Сбор работает только на HTTPS-адресе `itemun.github.io/aliva/`; локальный сервер и открытый с диска HTML не отправляют статистику. При смене домена обновите проверку адреса в `src/analytics.js`. Прошлые нажатия не восстанавливаются.

| Идентификатор цели | Что означает |
| --- | --- |
| `aliva_app_store_click` | Нажатие App Store и открытие сообщения о разработке |
| `aliva_google_play_click` | Нажатие Google Play и открытие сообщения о разработке |
| `aliva_pdf_download` | Личный PDF сформирован и браузеру передана команда скачать |
| `aliva_example_pdf_download` | То же для PDF на вымышленных данных, отдельно от личной конверсии |

Событие скачивания не подтверждает, что пользователь сохранил файл на диск: браузер такого подтверждения не предоставляет. Ошибка генерации и повторное нажатие во время генерации не создают цель. Повторное отдельное скачивание создаёт новое событие. Нажатия магазинов измеряют интерес, а не установки приложения.

## Настройки

В кабинете созданы четыре цели типа «Целевое событие» с точным совпадением идентификаторов из таблицы. Встроенный адаптер вызывает `ym(114646189, 'reachGoal', goal)` без дополнительных параметров.

Вебвизор, карта кликов, отслеживание ссылок и хешей, электронная коммерция и Тег Менеджер отключены в коде; автоматические цели, Вебвизор, электронная коммерция и Тег Менеджер также выключены в кабинете. Карточка анкеты и результата защищена классами `ym-hide-content ym-disable-clickmap ym-disable-submit ym-disable-keys`.

Ответы анкеты, диагнозы, страна, измерения и содержимое PDF не передаются. Метрика получает технические данные о посещениях и может использовать cookie. Для первого просмотра передаются адрес страницы без query/hash и только origin источника перехода. Описание конфиденциальности на сайте обновлено. Не включайте запись форм или автоматические цели при дальнейшей настройке счётчика.

CSP разрешает официальный тег `mc.yandex.ru`, ресурсы `yastatic.net` и соединения только с `mc.yandex.ru`, `mc.yandex.com`, `mc.yandex.kz`. Генерация PDF остаётся локальной и не зависит от загрузки Метрики.

Основание API: [инициализация](https://yandex.ru/support/metrica/ru/code/counter-initialize.html), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal), [защитная HTML-разметка](https://yandex.ru/support/metrica/ru/code/html-markup). Проверено 24.11.2026.

Для альтернативной интеграции доступно событие окна `aliva:conversion`, `event.detail` содержит только `{goal}`. Не подключать параллельно второй обработчик reachGoal, если включён встроенный адаптер: иначе будет двойной подсчёт. Адаптер не читает медицинские ответы и не сохраняет события в браузерное хранилище. До загрузки официального тега используется его стандартная очередь в памяти. Ошибка/блокировка счётчика не мешает интерфейсу и PDF.

Сборка и проверки:
```sh
npm run build
npm test
```
