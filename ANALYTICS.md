# Целевые действия Aliva

Подготовлены 23.11.2026. Сейчас счётчика нет: события доступны в браузере, не сохраняются и никуда не отправляются. Статистика появится после подключения Метрики; прошлые нажатия не восстанавливаются.

| Идентификатор цели | Что означает |
| --- | --- |
| `aliva_app_store_click` | Нажатие App Store и открытие сообщения о разработке |
| `aliva_google_play_click` | Нажатие Google Play и открытие сообщения о разработке |
| `aliva_pdf_download` | Личный PDF сформирован и браузеру передана команда скачать |
| `aliva_example_pdf_download` | То же для PDF на вымышленных данных, отдельно от личной конверсии |

Событие скачивания не подтверждает, что пользователь сохранил файл на диск: браузер такого подтверждения не предоставляет. Ошибка генерации и повторное нажатие во время генерации не создают цель. Повторное отдельное скачивание создаёт новое событие. Нажатия магазинов измеряют интерес, а не установки приложения.

## Когда будет счётчик

1. Установить официальный код своего счётчика. Для этой медицинской анкеты отключить Вебвизор, запись полей/содержимого, автоматические цели форм и любую передачу ответов. Карточка анкеты/результата дополнительно помечена `ym-hide-content`.
2. В `src/analytics.js` заменить `COUNTER_ID=0` на номер счётчика и пересобрать обе страницы. Альтернатива: после загрузки встроенного модуля вызвать `AlivaAnalytics.configure(НОМЕР_СЧЁТЧИКА)`.
3. Создать четыре цели типа «JavaScript-событие» с идентификаторами из таблицы. Адаптер вызывает `ym(id, 'reachGoal', goal)` без параметров профиля, страны, диагноза или содержимого PDF.
4. Текущая CSP в `src/landing.template.html` запрещает внешние скрипты и соединения (`connect-src 'none'`). При фактической установке счётчика нужно разрешить конкретные адреса официального тега и его запросов, проверить загрузку и достижение целей. Сейчас политика намеренно не расширена. Обновить описание конфиденциальности под реально подключённую аналитику.

Основание API: [Яндекс — reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal), проверено23.11.2026.

Для альтернативной интеграции доступно событие окна `aliva:conversion`, `event.detail` содержит только `{goal}`. Не подключать параллельно второй обработчик reachGoal, если включён встроенный адаптер: иначе будет двойной подсчёт. Модуль не имеет очереди, хранилища, идентификаторов посетителей или доступа к медицинским ответам. Ошибка/блокировка счётчика не мешает интерфейсу и PDF.

Сборка:
```
node outputs/aliva/build.cjs
node outputs/aliva/concepts/function/build.cjs
```
