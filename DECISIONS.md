## User-approved scope

- Russian-language landing page, Russia, adults only; age under 18 must not be accepted.
- Minimal questionnaire: sex, age, height, weight, waist circumference, smoking, diagnosed diabetes type.
- Diabetes options: not diagnosed; type 1; type 2; other or unknown type. Do not call types degrees.
- Smoking options: never regularly smoked; currently smokes; quit. Conditional duration and average cigarettes/day; years since quitting only for former smokers. Unknown quantities may be omitted.
- Height, weight, waist can be omitted / marked unknown; do not invent values.
- Waist measurement help and skip option.
- Default assumption: relevant examinations have not been performed for at least five years. This does NOT establish the last date for every examination, absence of prior abnormalities, or that all tests are overdue.
- Plan horizon: next year with future repeat intervals, not a fixed guaranteed five-year schedule.
- No registration; questionnaire answers stay in memory in the browser, with no persistence or server/AI transmission.
- User rejected a long questionnaire (family history, medications, operations, symptoms, pregnancy etc.). Do not add it back silently. Missing information still limits clinical eligibility.

## Visual and interaction decisions

- Preserve Aliva wordmark with plant/sprout, green/cream palette, serif hero and clean form typography.
- No page scrolling on ordinary supported screens; adapt by compact steps and replacing the form with help/result screens.
- Current base flow: profile -> measurements -> smoking -> diabetes. Smoking details appear as additional short steps only if applicable.
- Numeric input focus uses the whole rounded wrapper, including units; no rectangular inner-input outline.
- Mobile removes the large decorative/marketing hero, keeping the questionnaire and navigation visible.
- Verified earlier at 1440x900, 1024x600, 768x1024, 390x844, 360x640, 320x480, 812x375. Reduced-height input layout also inspected at 360x300. These are viewport checks, not physical-device certification.

## Implementation — 17.11.2026

- User agreed to browser-only fixed-rule calculation and explicitly requested implementation.
- Rules v1.0.0 are implemented; exact thresholds, source versions, limitations and test commands are in RULES.md.
- Base: Russian programme 404н; bounded clinical additions use ADA/USPSTF/NICE and verified Russian diabetes provisions. Conflicts and missing history are shown instead of automatically combining recommendations.
- Results now depend on answers, with purpose, timing, caveats and source tabs. The example uses an explicitly labelled synthetic profile and does not overwrite questionnaire answers.
- UI remains standalone and compact. Source is maintained in src/ and bundled via build.cjs. The frozen baseline remains unchanged.
- No independent clinical review, no deployment or publication. Technical test success does not establish clinical suitability.
- Answers are memory-only; no storage/transmission/AI. Unknown values are not normal values.
- Horizon is the next year with conditional repeat intervals. Rules require review by 01.03.2027; an expired version is visibly labelled.
