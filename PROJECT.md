# Прогресс Aliva

GitHub Issues хранит задачи и критерии готовности, GitHub Projects показывает их статус.

- [Сайт Aliva](https://itemun.github.io/aliva/)
- [Репозиторий Aliva](https://github.com/itemun/aliva)
- [Доска проекта](https://github.com/users/itemun/projects/2/views/1)
- [Задачи](https://github.com/itemun/aliva/issues)
- [Автоматическая сборка и тесты](https://github.com/itemun/aliva/actions)

Репозиторий и доска публичные; редактировать их может владелец и явно приглашённые участники. Доска показывает реализованные функции и следующие задачи; завершённые задачи закрыты в Issues.

## Работа с доской

- **Запланировано** — задача описана, но работа ещё не начата.
- **В работе** — задача выполняется.
- **Готово** — результат проверен, критерии готовности выполнены.

Новая задача: описать проблему, ожидаемый результат и способ проверки. Перемещать в «Готово» после проверки; незавершённые исследования не считать реализованной функцией. Даты релизов и исполнители заранее не назначены.

## Уже реализовано

- Лендинг, логотип и адаптивная анкета.
- Формирование планов для России и Казахстана.
- Локальный PDF: чек-лист, пояснения, прививки, привычки ВОЗ и глоссарий.
- Яндекс Метрика: посещения и четыре цели для PDF и кнопок магазинов, без передачи ответов анкеты.

## Следующие направления

- Независимая клиническая проверка правил и пояснений, особенно возрастных границ и расхождений программ.
- Проверка на реальных iPhone, Android и планшетах.
- Выбор собственного домена при необходимости; GitHub Pages уже используется для публикации.
- Описание первой версии приложения Aliva.

Актуальные статусы и критерии отдельных задач будут на доске. Медицинские ответы пользователей в задачи не добавлять.
