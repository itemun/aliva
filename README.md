# Aliva

**Сайт:** https://itemun.github.io/aliva/

Лендинг с короткой анкетой, планом профилактики для России и Казахстана и PDF для обсуждения с врачом. Приложение Aliva ещё не выпущено: кнопки магазинов открывают сообщение о разработке.

## Запуск

Требуются Node.js 22+ для сборки и тестов, Python 3 для локального сервера. Загрузка npm-зависимостей не нужна: PDF-библиотеки и шрифты находятся в `vendor/`.

```sh
npm run build
npm test
npm start
```

Откройте http://127.0.0.1:8771/. Для другого порта: `python3 -m http.server 8772 --bind 127.0.0.1`.

Готовый `index.html` также открывается как локальный файл. Скрипты приложения, шрифты и изображения встроены в HTML. На публичном сайте дополнительно загружается счётчик Метрики; локальная анкета и PDF от него не зависят. В репозитории хранится только этот итоговый HTML. Сборка также создаёт локальные `aliva-concept-function.html` (прежний адрес лендинга) и `aliva-landing.html` (промежуточная страница); они исключены из Git.

## Где править

| Файлы | Назначение |
| --- | --- |
| `src/rules.js` | Локальные правила формирования плана |
| `src/app.js` | Анкета, валидация, результат и скачивание |
| `src/pdf.js` | PDF, возрастные пояснения, глоссарий |
| `src/example.js` | Общий вымышленный профиль примера, расчёт текущими правилами |
| `src/analytics.js` | Согласие на Метрику, карта кликов вне анкеты и 13 целей без передачи ответов |
| `src/landing.template.html` | Базовый шаблон интерфейса |
| `concepts/function/` | Текущий дизайн, тексты, логотип и ресурсы |
| `tests/` | Автоматические проверки и сценарий проверки адаптивности |
| `research/` | Сохранённые тексты нормативных источников |

Старые концепции, скриншоты и эталонные снимки вынесены в отдельный локальный архив. В старой документации пути `outputs/aliva/...` отсчитываются от прежнего общего workspace; в этом репозитории корень уже соответствует папке `aliva`.

## Данные и ресурсы

Ответы анкеты обрабатываются локально в памяти браузера; не помещайте реальные медицинские данные в issues, скриншоты, коммиты или логи. В тестах используются вымышленные профили. SSH-ключи и токены не входят в репозиторий.

Лицензии сторонних PDF-библиотек и шрифтов сохранены рядом с ресурсами в `vendor/` и `concepts/function/fonts/`. Общая лицензия на исходники проекта пока не выбрана.

## Безопасность

Об уязвимостях сообщайте через [закрытый отчёт GitHub](https://github.com/itemun/aliva/security/advisories/new), без реальных медицинских данных. Не публикуйте ключи, токены или персональные данные в задачах. Actions запускаются с доступом на чтение; проверки из внешних pull requests требуют одобрения владельца. Сторонние PDF-библиотеки хранятся локально: обновления этих файлов нужно проверять отдельно от уведомлений Dependabot.

## Публикация

После изменений в `main` GitHub Actions собирает сайт и запускает тесты. Только после успешных проверок в GitHub Pages публикуются `index.html` и `favicon.svg`. Публикация из pull requests отключена; окружение `github-pages` разрешает только ветку `main`. Для отката выполните обычный revert нужного коммита: прошедшая проверки версия будет опубликована автоматически.
