# Aliva — current Function-inspired landing

Run `npm run build` from the repository root to build the base, apply this design, and produce `index.html`.

The shipped page is `../../index.html`. The build also produces the ignored local alias `../../aliva-concept-function.html`. All assets are embedded; no runtime network requests. Historical screenshots and frozen snapshots are archived outside the repository.

The page scrolls through how it works, the example, sources, and the questionnaire. The final section contains the existing question/result card and local PDF export. Start buttons scroll there without resetting answers. Feedback was removed from the page, application and generated PDF at the user's request.

See `../../RESPONSIVE-QA.md` and `../../VERIFICATION.md` for verification scope, and `../../DECISIONS.md` for decisions. Required image, badge, font and logo assets remain in this directory.
